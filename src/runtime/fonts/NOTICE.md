Symbols**, copyright 2013 Google Inc. They contain only Unicode code points
U+1F19B through U+1F1AC. `arib-enclosed-cjk.svg` and
`arib-enclosed-cjk.woff` are subsets of **Noto Sans CJK JP**, copyright
2014-2021 Adobe. They contain only the defined enclosed CJK symbols in
U+1F200 through U+1F251. Both sources are distributed under the SIL Open Font
License 1.1 in `OFL.txt`.

The source used for the checked-in subset identifies itself as “Noto Sans
Symbols, Version 1.09 uh” and embeds the same OFL declaration. The family is
exposed by the runtime as “ARIB Symbols” to avoid claiming the upstream name
for this modified subset.
